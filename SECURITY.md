# Security Policy

## Supported Versions

Only the latest release of browser-agent receives security fixes.

## Reporting a Vulnerability

Please do **not** open a public issue for security vulnerabilities.
Instead, report them privately via
[GitHub security advisories](https://github.com/inference-gateway/browser-agent/security/advisories/new).

Include a description of the issue, the affected component or
configuration, and reproduction steps if available. You can expect an
acknowledgement within 7 days and a status update within 30 days.
Please allow us to release a fix before any public disclosure; we will
credit reporters in the advisory unless they prefer otherwise.

## Deployment Hardening

See the [Security section of the README](README.md#security) for the
default tool sandbox, authentication (`A2A_AUTH_ENABLED`), and the
environment variables that widen or restrict access.
